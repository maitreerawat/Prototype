# Prototype Kit Plugin (`prototype-kit`)

A reusable Antigravity plugin containing system rules, subagent profiles, and skills for rapid software prototyping.

## Contents
- `rules/AGENTS.md`: Always-on prototyping principles and subagent orchestration patterns.
- `agents/`: Prompt specifications for specialized subagents (`architect.md`, `scaffolder.md`, `verifier.md`).
- `skills/rapid-prototype/SKILL.md`: Step-by-step workflow to turn an idea into a working prototype.
- `skills/agent-skill-factory/SKILL.md`: Meta-skill to author new stack-specific skills and subagents.
